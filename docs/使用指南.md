# DocClear 使用指南

DocClear 是一款**本地优先**的敏感信息脱敏工具：自动识别 PDF、Word、Excel、图片中的身份证号、银行卡、手机号、人脸等敏感内容，一键抹除。所有处理 **100% 在你的电脑上完成，无需联网、数据不出本机**。

产品形态：

| 形态 | 适用人群 |
|---|---|
| 桌面应用（Windows / macOS / Linux） | 日常办公，图形界面操作 |
| CLI 命令行 | 批量处理、脚本集成 |
| MCP 服务 | 接入 Claude Desktop / Cursor 等 AI 助手 |
| Web API | 集成到自有系统 |

## 二、快速上手（桌面端）

五步完成一次脱敏：

1. **导入文件**：把文件或整个文件夹拖进窗口（或按 `Ctrl/⌘ + O` 选文件、`Ctrl/⌘ + Shift + O` 选文件夹）。
2. **自动扫描**：导入后自动识别敏感信息，命中位置以彩色框标出。
3. **复核命中**：在右侧「命中复核」列表逐条确认——可定位到文档位置，也可把不该脱敏的条目标记为「跳过」。
4. **选择脱敏方式**：顶栏切换 涂黑遮罩 / 假名替换 / 字符掩码（详见下文），切到「脱敏预览」可提前查看效果。
5. **执行脱敏**：按 `Ctrl/⌘ + Enter` 或点击「开始脱敏」，输出文件与报告即生成。

## 三、支持的文件格式

| 格式 | 说明 |
|---|---|
| PDF | 文本型 PDF 走文本链路；扫描件 PDF 自动走 OCR 链路 |
| 图片 | jpg / jpeg / png / tif / tiff / bmp（OCR 识别） |
| Word | docx（正文、页眉页脚、脚注尾注、**批注与修订**均参与检测与脱敏） |
| Excel | xlsx（单元格文本、共享字符串、公式字符串常量、批注均参与；数值单元格命中自动转文本。桌面端为多工作表网格预览：工作表标签切换、命中单元格高亮、划词手动标记） |
| CSV | csv（自动识别 UTF-8 / GB18030 等编码与原分隔符，写回保持原编码，Excel 打开不乱码；桌面端为网格预览，命中单元格高亮） |
| Markdown | md / markdown（正文、表格、列表、引用块参与检测与脱敏；围栏代码块、缩进代码块、行内代码与链接 URL 不脱敏，结构原样保留） |
| PowerPoint | pptx（幻灯片正文与演讲者备注参与检测与脱敏；格式属性与 XML 结构原样保留；元数据同步清理。桌面端为文本视图，分幻灯片/备注部件展示） |

- **左栏**：已打开文件列表与状态；左右两栏都可用边界按钮收起，给小屏幕让位。

## 五、三种脱敏方式

顶栏随时切换，**每个文件独立生效**（未选中文件时设置的是新文件默认值）：

| 方式 | 效果 | 特点 |
|---|---|---|
| 涂黑遮罩 | 黑块覆盖 | 物理真删，**不可恢复**，最安全 |
| 假名替换 | 张三 → 人物A | 保持文档可读，附「假名↔原文对照表」**可还原** |
| 字符掩码 | 张三 → 张*、手机号 138\*\*\*\*8000 | 保留格式观感，适合展示场景 |

- 右栏每条规则还可**单独指定脱敏方式**（规则级覆盖），例如身份证涂黑、姓名用假名。
- 脱敏完成后切换方式会使旧产物失效，回到已扫描状态，可重新生成。

## 六、检测规则

右栏「检测规则」区按**当前文件**独立配置，不牵连其他文件：

- **规则模板**：内置 PII（26 类常见敏感信息，零配置可用）、标书专用、合同专用，下拉即换。
- **规则勾选**：只保留需要的规则，未勾选的不参与检测；带「AI」标记的规则为**离线 AI 模型识别**（姓名、公司名、地址等，推理在本机完成）。
- **白名单 / 自定义规则**：点「管理规则（黑白名单）」，可添加白名单词（命中也不脱敏）、自定义关键词与正则。
- **应用到全部**：把当前文件的规则配置套用到所有已打开文件（各自重扫）。
- **恢复默认**：一键回到全规则启用、清空白名单。

## 七、命中复核与手动标记

**命中复核列表**（右栏中部）每条命中支持：

- **定位**：点击放大镜，文档自动滚动并脉冲高亮该位置。
- **跳过**：点击后该条标记为「不脱敏」，原文保留；再点一次恢复。缩略图与列表会显示低置信度命中提醒，扫描件建议重点复核。

**手动标记**（自动检测之外的补充，重扫不丢失）：

- **框选**（PDF / 图片）：工具栏开启框选模式，在页面上拖画矩形涂黑该区域（`Esc` 退出框选模式，选中框后按 `Delete` 删除）。
- **划词**（docx / txt / xlsx / csv）：直接选中文字标记。
- **搜索标记**：用工具栏搜索框找到目标词后，把搜索结果批量标为手动脱敏项。

## 八、Word 批注与修订（审阅栏）

打开 docx 时，预览区右侧出现「审阅」栏，与 Word/WPS 审阅面板一致：

- 批注、删除修订以卡片列出，虚线牵引回正文锚点；插入修订内联显示在正文里。
- 批注/修订中的敏感内容同样被检测并高亮；切到「脱敏预览」后按当前脱敏方式展示，脱敏产物中的批注内容同步完成脱敏。

## 九、原文标注 vs 脱敏预览

- **原文标注**：显示原始文档 + 彩色类型框，用于复核「检测得对不对」。
- **脱敏预览**：脱敏前以黑块模拟最终效果（涂黑=纯黑块；假名/掩码=黑块+白色替换文字），用于确认「抹完长什么样」；脱敏完成后直接展示真实产物。

## 十、脱敏产物与导出

脱敏完成后（右栏「脱敏完成」区）可导出：

| 产物 | 说明 |
|---|---|
| 脱敏文件 | 与原文件同格式，**自动深度清除隐藏数据**（元数据、批注作者信息等） |
| 脱敏报告（HTML） | 可打印归档，**不含原始敏感文本**，可安全流转 |
| 假名↔原文对照表 | JSON 可用于回填还原 / CSV 供 Excel 查看；**含原始敏感信息，请妥善保管** |
| 纯文本导出 | 按当前脱敏方式导出全文（正文 + 页眉页脚 + 脚注尾注 + 批注；xlsx 为共享字符串 + 工作表 + 批注 + 图形文本） |
| 审查存档（.dclr） | 标题栏「保存审查」把当前工作状态打包存档，可随时「打开审查」恢复现场 |

**真删除验证**（PDF）：脱敏后可一键执行「文本层 + strings 扫描」双重验证，确认敏感内容已被物理移除、无法通过复制文本或二进制扫描找回。

## 十一、假名还原（专业版）

假名替换模式下脱敏的文档，可凭对照表还原：标题栏 →「假名还原」→ 选择脱敏产物与对照表，即可回填原文。

> 对照表是还原的唯一凭据，脱敏后请与脱敏文件分开妥善保存。

## 十二、设置（标题栏齿轮）

- **OCR 识别引擎**：本地 PaddleOCR（ONNX 运行时），模型按所选语言自动下载，仅影响扫描件识别；可选择识别语言。
- **渲染精度**：200 DPI（快速，批量大文件首选）/ 300 DPI（精细，小字号识别更准）。
- **置信度阈值**：低于阈值的 OCR 结果不作为命中；调低多报、调高漏报。
- **MCP Server**：在应用内一键构建本地 MCP 服务（需专业版或企业版授权），供 AI 助手调用。
- 支持应用内**检查更新**。

## 十四、CLI 命令行

CLI 适合批量处理与脚本集成。解压发行包后，可执行文件在 `bin/`，规则模板在 `plugins/redaction-rules/`。

### 基本用法

```bash
# 处理单个 PDF（自动判断文本/扫描件链路）
docclear -i input.pdf -o output/

# Office 文档（docx / xlsx）同样支持，原格式写回（xlsx 保留工作簿结构）
docclear -i 表格.xlsx -o output/

# 处理整个目录（递归扫描，自动并发）
docclear -i ./pdfs/ -o output/

# 指定处理链路：auto（默认）/ text（仅文本）/ scan（仅 OCR）
docclear -i input.pdf -o output/ -m text

# 指定规则模板
docclear -i 标书.pdf -o output/ -t bidding-doc

# 列出所有可用模板
docclear list-templates
```

### 只扫描不脱敏

```bash
# 文本输出
docclear scan -i input.pdf

# JSON 输出（便于程序处理）
docclear scan -i input.pdf --format json
```

### 报告与对照表

```bash
# JSON 脱敏报告（多文件时按文件名自动派生）
docclear -i ./pdfs/ -o output/ --report output/report.json

# HTML 报告 / 批量汇总报告
docclear -i ./pdfs/ -o output/ --report-html output/report.html
docclear -i ./pdfs/ -o output/ --batch-report output/batch.json

# 假名化映射表（仅假名模式）；--mapping-input 可载入既有映射表续编号（跨文件代号一致）
docclear -i ./pdfs/ -o output/ --mapping output/mapping.json
docclear -i ./more/ -o output/ --mapping output/mapping.json --mapping-input output/mapping.json
```

### 批量与容错

```bash
# 指定并发度（默认 min(4, 核数)）
docclear -i ./pdfs/ -o output/ -j 8

# 扫描件关键词模糊匹配（容忍 OCR 识别误差）
docclear -i ./scans/ -o output/ --fuzzy

# 失败重试次数 / 断点续跑（跳过已有非空输出）
docclear -i ./pdfs/ -o output/ --retry 2 --resume

# 指定配置文件（默认读取当前目录 config.toml）
docclear -i input.pdf -o output/ -c my-config.toml
```

## 十五、MCP 服务（AI 助手集成）

`docclear-mcp` 通过 stdio 与 AI 助手通信。以 Claude Desktop 为例，编辑
`~/Library/Application Support/Claude/claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "docclear": {
      "command": "/path/to/docclear-mcp",
      "args": []
    }
  }
}
```

可用工具：

| Tool | 说明 | 参数 |
|---|---|---|
| `redact_document` | 脱敏处理 | `input`, `output`, `template?`, `mode?` |
| `scan_document` | 仅扫描 | `input`, `template?`, `mode?` |
| `list_rules` | 列出规则 | `template?` |

配置后直接向 AI 助手提需求即可，例如：

> 请帮我脱敏这个文件：/path/to/contract.pdf，输出到 /path/to/output/，使用合同规则模板。

## 十六、Web API

```bash
# 启动（默认端口 3900）
docclear-web

# 自定义端口 / 启用 API Key 认证
DOCLEAR_PORT=8080 docclear-web
DOCLEAR_API_KEY=your-secret-key docclear-web
```

```bash
# 健康检查
curl http://localhost:3900/healthz

# 上传 PDF 并脱敏

  -F "file=@contract.pdf" \
  -o redacted_contract.pdf

# 指定模板与链路；带 API Key
curl -X POST "http://localhost:3900/redact?template=bidding-doc&mode=text" \
  -H "X-API-Key: your-secret-key" \
  -F "file=@bid.pdf" \
  -o redacted_bid.pdf

# 只扫描（返回 JSON 命中明细）
curl -X POST "http://localhost:3900/scan?template=builtin-pii" \
  -F "file=@contract.pdf"
```

## 十八、常见问题

**Q：处理过程会上传文件吗？**
不会。检测、OCR 推理、脱敏替换全部在本机完成，无需联网。

**Q：涂黑的内容还能恢复吗？**
不能。涂黑遮罩是物理真删（文本层移除 + 黑块覆盖），并可通过「真删除验证」复核。需要可回溯的场景请使用「假名替换」并保管好对照表。

**Q：扫描件识别不准怎么办？**
在设置中：确认识别语言正确、把渲染精度调到 300 DPI、适当调整置信度阈值；个别漏项用「框选 / 划词」手动补标。

**Q：批注里的敏感内容会脱敏吗？**
会。docx 的批注与修订（插入/删除）、xlsx 的单元格批注都参与检测与脱敏，可在 Word 审阅栏 / Excel 批注浮层中直接复核效果；批注作者信息在导出时统一清除。

**Q：脱敏会改动排版吗？**
docx 采用文本部件级回填，格式零损失；xlsx 原地改写单元格文本（数值单元格命中会转为文本单元格，列宽行高不变）；PDF 在原位覆盖，版式保持不变；同时自动清除文档隐藏数据。
